# FocusFlow

FocusFlow is a task management and Pomodoro timer application designed to help users enhance their focus and manage their work efficiently. It combines robust task organization with a configurable Pomodoro timer to promote productivity and well-being.

## ✨ Key Features

*   **📝 Task Management:**
    *   Create, edit, and delete tasks with titles, descriptions, due dates, and priorities (Low, Medium, High).
    *   Organize tasks with subtasks and attach relevant file names.
    *   Mark tasks as complete.
*   **📋 Kanban Boards:**
    *   Organize tasks into multiple customizable boards (e.g., "To Do", "In Progress", "Done").
    *   Easily move tasks between boards.
    *   Create and delete boards as needed.
*   **🍅 Pomodoro Timer:**
    *   Integrated Pomodoro timer with customizable work, short break, and long break durations.
    *   Track Pomodoro sessions and link them to specific tasks.
    *   Sound notifications for timer events (can be toggled).
    *   Controls to start, pause, reset, and skip timer phases.
*   **📊 Statistics:**
    *   View statistics on completed Pomodoro sessions.
    *   Track time spent on focused work for different tasks.
    *   Visualize data with charts (sessions per day, time per task).
*   **⚙️ Customization & Settings:**
    *   **Theme:** Switch between Light and Dark mode.
    *   **Task Card Templates:** Choose from different visual styles for task cards (Minimalist, Colorful, Professional).
    *   **Language:** Change the application language (supports multiple languages including English, Spanish, French, etc.).
    *   **Pomodoro Settings:** Adjust default durations for work, short breaks, long breaks, and sessions before a long break.
    *   **Notifications:** Enable or disable sound notifications.
*   **🌐 Offline Functionality:** All tasks, boards, and settings are stored in the browser's local storage, allowing for offline access and persistence of data.
*   **📱 Responsive Design:** The application is designed to work seamlessly across different screen sizes.

## 🛠️ Tech Stack

*   **Frontend:** React, TypeScript
*   **Styling:** Tailwind CSS
*   **Routing:** React Router
*   **State Management:** React Context API
*   **Icons:** Heroicons (via custom SVG components)
*   **Charting:** Recharts (loaded via CDN)
